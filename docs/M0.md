# AmiRender M0

## Definition of done

M0 establishes the contracts required to build the first real appliance.

1. Job schema
2. Node capability schema
3. Engine adapter interface
4. Controller/node architecture
5. Amiga client protocol notes
6. Deterministic null engine fixture

## Architecture

```text
AmigaOS/m68k
  AmiRender CLI / ARexx / future library
             |
          TCP/IP
             |
     AmiRender Appliance
       controller
       scheduler
       asset cache
             |
       engine adapter
             |
   local ARM64 CPU / farm
```

## Support levels

- Native Accelerated: renderer runs natively on appliance/farm.
- Translated Accelerated: classic scene is translated into AmiRender IR and rendered by a modern backend.
- Original Compatible: original m68k renderer executes under AmiVM for fidelity.

## First implementation sequence

M0: null engine and protocol.
M1: POV-Ray native backend + one Amiga client.
M2: LightWave adapter and capability discovery.
M3: Imagine + asset cache + ARexx.
M4: AmiTerrain/Ami3D native integration.
M5+: Blender/Cycles farm integration and classic-format expansion.
