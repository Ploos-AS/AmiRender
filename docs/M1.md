# M1 — POV-Ray backend and first real client path

## Goals

1. Promote the M0 engine contract into Go packages.
2. Add POV-Ray as the first production renderer.
3. Execute POV-Ray without a shell.
4. Add a deterministic smoke scene.
5. Integrate the adapter with the node protocol.
6. Add the first AmigaOS/m68k submission client.

POV-Ray is an external runtime dependency. AmiRender does not vendor or redistribute it.

## Security boundary

Scene paths and render options are passed as process arguments, never interpolated into a shell command. The appliance will later add job-root path confinement and an asset cache.
